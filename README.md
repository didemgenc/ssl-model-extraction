# Leveraging Self-Supervised Learning for Low-Budget Model Extraction

Code to reproduce every table of the paper (revised version). Each table below lists the script
that produces it, the exact command, and where the results are written.

```
cifar10/      CIFAR-10 experiments (Tables 1, 2, 4, 5; MixMatch inputs)
svhn/         SVHN experiments (Table 2, SVHN rows; Table 3)
mixmatch/     MixMatch model-extraction baseline on our victim / query set / test split (Table 2)
thermal_guard.sh   optional: pauses a run when the CPU overheats (laptop use)
```

## Setup

```
pip install -r requirements.txt
git clone https://github.com/YU1ut/MixMatch-pytorch mixmatch_github   # only for the MixMatch baseline
```

Paths are resolved through `paths.py` in each folder. On a new machine set:

| Name | Meaning |
|---|---|
| `DATA_DIR` | folder with the pre-computed `.pkl` datasets, the SimCLR encoder (`resnet50_cifar10_bs1024_epochs1000.pth.tar`) and the victim model (`wide-resnet-40x10.t7`) |
| `DATASET_ROOT` | torchvision root containing `cifar-10-batches-py` (and the SVHN files for `svhn/`) |
| `data_path(name)` | `outputs/name` if the file was regenerated by a script in this repo, otherwise `DATA_DIR/name` |
| `out_path(name)` / `ckpt_path(name)` | `outputs/` and `checkpoints/` inside the folder (git-ignored) |

Run every script from inside its folder (`cd cifar10 && python ...`) so that `models/` imports resolve.

### Data

Data files are not part of the repository. They are produced by the original pipeline
(`Step1_* ... Step4_*`, see "Pipeline" below) and are available from the authors on request:

* `{4k,2k,1k,250}_target_labeled_dataset.pkl` – query set (CIFAR-10 test images) with the victim's labels
* `random_{budget}_test_dataset.pkl` – the 6000-image held-out test split of each budget
* `transfer_dataset/{sim}substitute_threshold/{budget}_{conf}_confidence+cossim_labeled_dataset.pkl` – two-stage pseudo-labelled training sets (Step 4 output)
* `resnet50_cifar10_bs1024_epochs1000.pth.tar` – SimCLR ResNet-50 encoder, `wide-resnet-40x10.t7` – victim model

## Evaluation protocol (revised version)

Every experiment is repeated with five random seeds (950, 1, 2, 3, 4). Models are trained for a fixed
number of epochs and the **final-epoch** model is evaluated (no model selection on the test set).
Tables report mean ± std of test accuracy and of **fidelity** (label agreement with the victim on the
same 6000-image test split, Jagielski et al. 2020). `eval_fidelity.py` computes accuracy and fidelity
for any checkpoint; `summarize_table*.py` aggregates the CSVs.

## Table 1 – semi-supervised baseline extracted model (CIFAR-10)

```
cd cifar10
bash run_table1.sh 950 1 2 3 4                 # 4 budgets x {frozen,layer4,finetune} x {linear,MLP} x 5 seeds
python eval_fidelity.py --glob 'table1/*.pth'  # accuracy + fidelity of all checkpoints -> outputs/fidelity_results.csv
python summarize_table1.py                     # mean ± std table -> outputs/table1_summary.csv
```
Script: `table1_baseline.py` (parameterised rewrite of `Encoder_Finetune_Eval_with_target_labeled_dataset.py`,
same recipe: SGD lr 0.1, momentum 0.9, batch 128, 20 epochs, random crop + flip).
F = `--training_method frozen`, LL = `layer4`, FT = `finetune`. Results of our runs: `outputs/table1_results.csv`,
`outputs/fidelity_results.csv`, `outputs/table1_summary_final.csv`.

### MixMatch baseline on the same victim / query set / test split

```
cd cifar10 && python export_mixmatch_inputs.py      # query indices + victim labels, test split, victim predictions
cd ../mixmatch && bash run_mixmatch.sh 128 4k 2k 1k 250
```
`train_mixmatch_mea.py` uses the WRN-28-2 model and the MixMatch step of `mixmatch_github` (unmodified)
with the default hyper-parameters; labeled set = our query set with the victim's labels, unlabeled set =
CIFAR-10 training set, test = our 6000-image split, EMA model after the final epoch, no validation set.
Results: `mixmatch/outputs/mixmatch_results.csv`, per-epoch log in `mixmatch/outputs/<run>/log.csv`.

## Pipeline (original scripts, kept unchanged apart from path handling)

1. `Step1_Chose_4k_target_labeled_dataset.py` – per-class balanced query set + fixed 6000-image test split
2. `Step2_QueryAndLabel_4k_target_labeled_dataset.py` – query the victim, build the transfer dataset
3. `Encoder_Finetune_Eval_with_target_labeled_dataset.py` – baseline extracted model (Table 1)
4. `Step4_Proposed_Method_v2.py` – two-stage pseudo-labelling (confidence, then feature similarity)
5. `Step5_TrainAndEval_SusbtituteModel.py` – train the final extracted model on the pseudo-labelled set

Logs of the original runs are in `*/logs_original/`.
